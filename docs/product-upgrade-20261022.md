# 产品完善实施与验收（2026-10-22）

本次实施原清单 1–16、18–20、23–27，共 24 项。17（智能歌单）、21（备份恢复）、22（更新帮助诊断）、28（持续验收平台）未实施。本次独立功能回归用于交付检查。

旧版曲库首次运行会补读新增标签，保留歌曲身份与收藏；重新定位后的文件继续按稳定身份更新。

没有发行标识的同名、同艺术家、同年份版本无法可靠自动区分；不把任意歌曲备注当作发行版本。

## 设计对齐

使用内置 imagegen 的文生图模式生成两个参考板，原图与完整提示词保存在 `design/product-upgrade-20261022/`。主界面按参考图比例落实：顶部 50、侧栏 168、队列默认 254、底部播放栏 80 个 WPF 布局单位；主封面 176×176，主操作高 34；小窗口相应收紧。歌单、下载、音频、歌词页面沿用参考板的操作分组、竖向均衡器、对齐表单与右侧页脚操作。

保留产品现有品牌图标、来源切换和 13 个主题。示例封面和曲目只用于隔离验收资料，不写入用户曲库。

## 验证证据

所有动态验证使用隔离的 `CHILIMUSIC_DATA`，资料根目录为 `.local/validation/product-upgrade-20261022/`。

- `verified-product/product-verification.json`：产品功能与参考页面渲染结果。
- `verified-product/download-verification.json`：真实 HTTP 测试服务的暂停续传、SHA-256 完整性、追加、失败隔离与重试、保留清理、取消临时文件和快速暂停 / 继续。
- `verified-desktop/usability-verification.json`：既有播放、队列、浏览恢复及 13 个主题、273 组桌面窗口 / 页面布局回归。
- `verified-desktop/browse-verification.json`：分页、嵌套返回、搜索清空、选中项、滚动、快速返回与取消请求检查；尚未恢复完成就再次导航时保留目标状态。
- 手机网页在本机隔离服务中检查配对、队列调整、曲库列表播放、手机接管、暂停和断线提示；截图保存在相应验证资料目录。

实际桌面渲染使用本机 175% 缩放，主窗口覆盖 900×610、1120×700、1200×800 布局单位以及浅深主题。另已验证横向滚动条尺寸、横向滚动，以及 900 宽专辑操作组不溢出。截图检查覆盖专辑头部、详细表格、队列、歌单、带多种状态的下载任务、音频设置、歌词外观和标签表单。

真实 DAC 拔插、不同实体显示器 / DPI 切换、Android / iOS 后台播放、真实账号的网络波动和版权权益仍需要对应硬件与账号环境实测；隔离服务或模拟设备失效路径不代表这些场景已经实测。

## 本地交付

`dist/chilimusic.exe` 为 1.3.5 发行构建。`启动本地版.cmd` 可利用仓库已有的 .NET 8 运行环境启动此文件。正式安装包为 `release/chilimusic-1.3.5-setup-x64.exe`；版本发布入口为 https://github.com/sawanolin/chilimusic/releases/tag/v1.3.5 。本文和设计参考保留在源码仓库，不随安装包分发。

## 专辑封面修复

修复详情头部只读取列表缩略图、不主动请求服务器封面的遗漏。头部独立按当前详情获取封面，支持本地封面、专辑与歌单封面标识、歌曲封面回退；取消过期请求并核验当前详情，避免串图。单独验证返回、隐藏后重新显示、主题及窗口尺寸变化。封面回归记录位于 `.local/validation/cover-fix-20261022/cover-verification.json`。
