# 验证记录

环境：Windows x64，175% 显示缩放，.NET 8，libmpv 3186d369f9。

## 界面

- 主窗口：浅色、深色、900×610 最小尺寸、最大化与恢复。
- 设置：顶部、滚动底部、最小高度、主题下拉框；地址、中文用户名、英文升降部字符和密码显示。
- 输入框字体高度约 15.9 DIP，可用内容高度约 23.7 DIP，未被上下内边距裁切。
- 主窗口、设置和音频信息窗口：四个角透明，内部背景遵循同一裁切边界；主窗口圆角为 10 DIP。
- 迷你窗口、列表与队列右键菜单、系统托盘菜单：浅色和深色检查。
- 主任务栏：确认子窗口嵌入和八处按钮空白区域命中，无封面音符居中，专辑封面保持方形。
- 对实际编译程序集提取图标资源，与最终无辣椒 PNG/ICO 的 SHA256 比较一致。

## 播放与构建

- 测试 Navidrome 的连接、目录、歌手、专辑、歌单、搜索、收藏及系统媒体控制。
- MP3、FLAC、APE、WAV、M4A 和 AAC 的本地解码、暂停稳定性及定位检查通过。
- 独立本地模式的 WAV 和 Opus 播放、暂停、定位及队列保存检查通过。
- 未配置服务器时可以打开本地音乐并保存主题、托盘等设置。
- 不内嵌 MiSans 的源码构建能够启动，使用系统字体并播放本地 Opus。
- 依赖准备脚本使用官方压缩包完成 DLL 提取与 SHA256 校验。
- 独立便携版实际启动检查通过。
