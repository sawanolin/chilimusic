## Secondary windows

Use case: ui-mockup. Asset type: a high fidelity design reference board for secondary windows of the existing Windows WPF desktop music app chilimusic. This board will be translated into working native code, so design realistic controls and usable information hierarchy.
Create a clean 2 by 2 board showing FOUR different compact application windows, straight-on, extremely crisp Simplified Chinese interface, no perspective, no device frames. Landscape board approximately 1800x1400. All four windows must share the same disciplined design system as a mature desktop music player: blue-gray #EDF3F7 background, near-white #F9FBFC surfaces, navy #263443 typography, blue #3478F6 for one primary action per context, 8px corners, thin separators, restrained iconography, clear 8/16/24px spacing, aligned 32px high controls. Each window has simple titlebar and close button.
Top left window: 歌单管理. Left narrow playlist list with 3 playlists and quiet plus icon. Right header shows playlist name 夜航收藏 and caption 本地歌单 · 24首. Under it one aligned action bar: primary 播放; secondary 添加歌曲; overflow ellipsis for rename, cover, description and export. Track list fills remaining area with song titles, artists, durations. Bottom only subtle selection count and compact remove / move icons. Do NOT put create, rename, edit cover and description fields on the screen at the same time.
Top right window: 离线下载. Header shows used/total storage with thin capacity progress bar and muted note 始终保留的歌曲不会自动清理. ONE toolbar: primary 下载当前歌曲, secondary 下载队列, ellipsis. Two tabs 下载任务 / 已下载. Task rows show cover placeholder, song name, state and a thin progress bar with percentage. Each row has contextual pause/resume/retry icon and overflow, not a row of global action buttons. A subtle text link 管理缓存 at lower right. Keep task list the focus.
Bottom left window: 音频输出 settings. Left category navigation 常规 / 音频输出 / 快捷键 / 本地音乐 / 离线缓存. Right content has section 输出设备: a label left, wide device dropdown, icon refresh. 独占模式 uses a compact right-aligned toggle row with explanatory subtitle. 响度均衡 dropdown in aligned label-control grid. Equalizer is a separate collapsible area with preset selector and ten vertical slim sliders in a single compact card. Sticky footer uses neutral 取消 and single blue 保存, consistently aligned bottom right.
Bottom right window: 歌词外观. Main area is a tasteful live lyric preview showing 夜色轻轻落在窗前 with secondary next line. Below it aligned form rows 字号, 行距, 桌面背景, 文字颜色 with appropriate sliders and swatches, numeric values aligned right. Sticky footer: 恢复默认 as quiet link left; 取消 and blue 保存 right.
Constraints: no excessive pill buttons; no wrap panel full of equal-weight buttons; no huge empty gaps; no unnecessary outlines around every label; no decorative marketing copy. Focus on very attractive button alignment and a buildable consistent native desktop UI.
