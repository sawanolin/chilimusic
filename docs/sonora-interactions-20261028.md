# Sonora 操作逻辑对齐

本轮保留 C# / WPF 实现，参考 Sonora 的 `shared/cards.rs`（卡片浏览与播放分别处理）和 `shared/page.rs`（当前播放项控制与页面状态）。

- 专辑、歌手和歌单卡片单击进入详情；播放按钮独立处理。按修饰键选择、拖动、右键操作不会误触导航。
- 增加前进按钮、Alt+← / Alt+→ 和鼠标侧键导航。返回 / 前进保留分页数据、选择、滚动、筛选、歌曲排序和本地视图。
- 新页面重置歌曲排序；返回时恢复该页面的排序，避免上一张专辑的排序影响下一张。
- 本地视图选择框改为双向绑定，返回后与实际页面同步。
- 当前页面与播放队列一致时，页面主按钮切换为暂停 / 继续，保留当前歌曲和位置；其他列表仍从该列表开始播放。
- 队列多选后的 Delete 与右键移除使用同一批量操作；Ctrl+Z 一次撤销整个批次。筛选后的重复歌曲按队列位置移除。
- 切换音乐来源或服务器时清理前进历史，避免返回旧来源的页面。

验收使用隔离资料目录：`--qa-appearance --qa-interactions-only` 运行 14 项交互检查；完整 `--qa-appearance` 同时生成 50 张浅深色页面截图。原有 `--qa-browse` 验证分页、返回恢复及取消过期请求，`--qa-product` 验证队列、下载、本地曲库和全部主题布局。

本轮更新本地 `dist`，不变更应用版本号或发布线上安装包。

验收结果：14 项新增交互检查、7 项原有浏览恢复检查、18 项原有产品检查通过；15 套主题的 30 组主窗口布局通过；原生 EXE 完整外观验收输出 50 张截图并通过。检查记录位于 `.local/validation/sonora-native-20261028-final/`、`sonora-browse-20261028/` 和 `sonora-product-20261028/`。
