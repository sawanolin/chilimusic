## 实现原则

1. 每个区域一个主要操作，其他操作按上下文放入菜单。
2. 列表占据主体，低频编辑表单按需打开。
3. 按钮统一高度、间距与对齐；窗口底部使用固定操作区。
4. 下载使用任务 / 已下载分类，逐项控制暂停与重试。
5. 均衡器采用十段竖向滑块，歌词设置提供实时预览。

设计图为布局参考，图中样例歌曲、封面和示意数据不随产品使用；实际界面保留已有主题及功能边界。

生成方式：内置 imagegen 文生图。完整[提示词](prompts.md)随设计图保存。
