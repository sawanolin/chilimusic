# Sonora 界面对齐

采用 C# / WPF 实现，参考 Sonora 提交 `0e9624ee48e274508c615d7f40a83a8afeac2566`。

- `crates/ui/src/theme.rs`：移植中性浅色 / 深色主题，跟随系统默认使用这两套主题；原有配色仍可选择。
- `crates/ui/src/palette.rs`：C# 移植 24 色相分桶、相邻色聚合和次主色提取，限制采样尺寸；灰阶封面不生成伪强调色。
- `crates/ui/src/button.rs`：主按钮、描边按钮、图标按钮的悬停、按下、焦点和禁用状态；菜单支持勾选项、快捷键及子菜单。
- `crates/views/src/shared/cards.rs` 与 `shells/workspace.rs`：侧栏、卡片、详情标题区、表头、队列及底部播放栏的层次和间距；歌手封面采用圆形。
- `crates/views/src/shells/fullscreen.rs`：沉浸播放的大封面、封面色氛围、左对齐歌词、当前行突出、邻近行淡出及轻微模糊。继续使用原有歌词时序、手动滚动暂停跟随、翻译与定位逻辑。
- 设置、音乐工具、账号、迷你播放器和手机网页共用新的主题与控件样式。

移植来源与许可证见 `licenses/Sonora-NOTICE.md`。未引入 Sonora 的标识、宣传截图或音乐封面资源。

## 本机验收

`--qa-appearance` 在 `CHILIMUSIC_DATA` 指定的隔离目录生成测试音频和封面，输出浅深色曲库、详情、900×610 小窗口、7 个设置页、4 个音乐工具页、账号、迷你播放器及歌词截图和 `appearance-report.json`。

其余使用已有的 `--qa-product`、`--qa-immersive` 与 `--qa-quality` 检查曲库布局、播放行为、歌词滚动、进度拖动及音质标识。测试目录与生成文件均留在 `.local/validation/`，不使用用户的曲库和登录配置。

本次结果：Release 构建与本地 `dist` 发布成功，0 警告、0 错误；原生 EXE 的外观验收通过并输出 50 张截图；产品验收 18 项通过，15 套主题 × 2 种主窗口尺寸通过；沉浸播放 30 组布局、歌词平滑跟随、进度拖动及取消通过；音质标识 30 组布局与 4 种渲染比例通过。

最终外观记录：`.local/validation/sonora-final-2/appearance-report.json`；其他记录分别位于 `sonora-product-unrestricted`、`sonora-immersive`、`sonora-quality` 目录。

本次为界面开发，不变更应用版本号或发布线上安装包。
