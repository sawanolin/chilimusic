# 播放界面与桌面歌词调整（2026-11-13）

- 迷你播放器按内容计算高度，展开按钮改用有额外余量的独立列，避免高 DPI 下裁切；弹出定位按布局后的实际高度计算。
- 主窗口与迷你播放器的窗口控制按钮关闭默认虚线焦点装饰，保留悬停和按下样式。
- 桌面歌词取消底板和边框，使用白字与阴影（可自定义颜色）。悬停显示 A− / A+、锁定、关闭及右下角缩放手柄；滚轮调整独立桌面字号（14–72），拖动文字移动。字号、宽高保存在配置中；锁定后保留点击穿透与托盘解锁。
- “歌词外观”中用独立桌面字号替代已经无效的底板透明度设置。旧透明度配置字段保留以兼容旧配置。
- 左侧增加“所有歌曲”，适用于本地音乐和 Navidrome，复用分页、筛选、浏览历史和播放完整列表。重启可恢复此入口；网易云来源隐藏此入口。
- Navidrome 使用 search3 的空 query、songOffset 分页，albumCount / artistCount 均为 0，依据 OpenSubsonic 规范：https://opensubsonic.netlify.app/docs/endpoints/search3/ 。没有从实际用户服务器验证本次修改，验证使用内存 HTTP 响应。
- 专辑详情图片采用 Uniform 显示，去掉封面圆角和图片裁切；歌手头像保持原有圆形。
- 保留封面取色渐变：先用浮点数合成主题背景与光晕，再以稳定的亚色阶噪声量化到最终像素，避免低透明度渐变的阶梯。按 DPI 缓存位图，封面、主题或尺寸变化时重建；底部平滑衔接主题背景。
